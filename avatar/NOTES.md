# 头像设计方向：未闭合的圆

放弃了以照片二创为基础的头像方案，改为纯原创抽象符号：一笔未闭合的圆环（ensō 式），暖橙色收笔。保留三个版本，均为矢量 HTML/SVG 源文件，位于 `drafts/`。

## 三版寓意

**F · 原版**（`vf-swoosh`，米白底 / 深蓝墨色描边 / 橙色收笔点）
一笔画不闭合的圆——留白处是缺口，暗示"不完美但真实"。收笔一点暖橙，是理性表达之后落下的温度。克制、书法感，日常主头像。

**F1 · 冷暖渐变笔**（`vf1-gradient`，深空底）
描边本身从深蓝渐变到暖橙，不再单独用一个点收笔——"理性到温度"的过渡直接写进这一笔的走势里。最贴合账号"理性打底、故事收尾"的调性，是当前最推荐的正式版本。

**F4 · 暖底反转**（`vf4-warmbg`，暖橙底 / 深蓝描边 / 米白收笔点）
把主色和底色对调：暖意做底，理性（深色笔画）浮在上面。同一个符号的另一种情绪，留作节日、活动或"亮色皮肤"场景的备用头像。
