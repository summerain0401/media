# AI 工具小白系列教程规划（WorkBuddy → Claude Code）

- 制定日期：2026-07-14
- 主阵地：小红书（两条线都做）+ 公众号跟随；X 不单独开工，教程拆单点技巧当短推素材
- 定位：面向零基础普通人，从"人人下载就能用"升级到"高手都在用的"，最后对比收官
- 滚动修订：每期发布后按数据调整后续选题顺序

## 总设计

三段式递进，全程约 6-8 周，正好覆盖冷启动第 1 阶段（第 6 周检查点可用本系列数据判断选题方向）：

1. **WorkBuddy 篇（入门段，4-5 期）**——国内直接下载、免费起步、零门槛，负责冲搜索流量和藏赞
2. **对比过渡篇（1 期）**——承上启下："AI 同事"和"AI 全能助理"是两种东西
3. **Claude Code 篇（升级段，4-5 期）**——上限更高但有门槛，负责建立专业信任和人设厚度

启动前置条件：AI 复利篇探针测试通过（24h 曝光 ≥100），账号权重确认正常后系列开跑。

## 红线（每期发布前对照）

- **Claude Code 各期在小红书严禁出现**：注册教程、海外账号获取、支付/代充、网络环境（VPN/翻墙/魔法等词零容忍）。只讲"已经能用的人怎么用好"，获取途径最多一句"用你手头能用的入口"带过。公众号版可以坦率说明"有门槛"，但同样不教绕过方法。
- 所有期数照常过 `/content-review`。
- 声明非商单：WorkBuddy 篇找自然位置说明自费实测、非合作（避嫌 + 人味）。
- 时效标注：两款工具迭代都快，正文标注实测版本和日期；老笔记过期后评论区引导到新篇。

## 期数排布（初版，按数据滚动调整）

### 第一段：WorkBuddy（每期一个任务场景，不做功能罗列）

| # | 场景 | 一句话选题 |
|---|------|-----------|
| 1 | 开箱 + 第一个任务 | 下载装好 10 分钟，让 AI 把你乱了三年的下载文件夹整理干净 |
| 2 | 表格/数据 | 一堆发票/账单/流水，扔给它自动汇总成一张表 |
| 3 | PPT/文档 | 周五下班前要交的 PPT，让 AI 先干一小时 |
| 4 | 批量文件 | 上千张照片/文件批量重命名、归类，手动一下午 vs AI 几分钟 |
| 5 | 翻车实录 | 它干不了什么：我这几周踩过的坑（建立信任 + 为升级篇埋钩子）|

### 第二段：对比过渡（1 期）

| # | 场景 | 一句话选题 |
|---|------|-----------|
| 6 | 对比 | WorkBuddy 用了一个月，我为什么还要学 Claude Code——两种 AI 的分工 |

设计要求：不能用 Claude Code 的读者也要有收获（看懂两类工具的区别本身就是认知增量），不制造"你用的是低配版"的劝退感。

### 第三段：Claude Code（面向不写代码的普通人，差异化空位）

| # | 场景 | 一句话选题 |
|---|------|-----------|
| 7 | 认知篇 | 程序员的 AI 工具，不写代码的人拿来干什么 |
| 8 | 本地任务 | 同样是整理文件，它和 WorkBuddy 差在哪（顺带回扣对比）|
| 9 | 数据问答 | 把 Excel 扔进去直接用嘴问数据 |
| 10 | 写作工作流 | 让它管你的笔记/文档库，写东西快一倍 |
| 11 | 收官对比 | 什么活给谁干：一张决策图收尾整个系列 |

各期场景可换可增删，原则：每期解决一个具体痛点、标题利益型（发布前自问：搜索框里谁会搜到这篇）。

## 节奏与平台分工

- **小红书**：每周 3-4 篇里教程占 2 篇，剩余 1-2 篇维持热点评/观点认知配比（防止做成纯工具号）。系列建合集（合集名用描述性名称如"AI 工具零基础上手"，不设子栏目品牌，遵守账号命名约定）。
- **公众号**：每周 1 篇跟随，可两期小红书合并成一篇深度版；Claude Code 段公众号版本写得比小红书深（门槛、原理、边界都可展开）。
- **X**：不开教程线。每期拆 1-2 个单点技巧发短推（每天 0-2 条额度内），回复引流照旧。

## 篇间反模板提醒

教程系列最容易篇篇同构（痛点开场→步骤→总结）。每期动笔前照常翻前 2-3 篇，开场类型轮换：翻车经历开场、数据反差开场（"手动 4 小时 vs 7 分钟"）、对话开场、新闻由头开场等。步骤讲解允许，但骨架和开场不得连续两期相同。

## 数据观察点（并入每周日复盘）

- 教程篇 vs 非教程篇的曝光/藏赞比对比——验证 70% 干货配比是否成立
- 第 1 期（WorkBuddy 开箱）是系列探针：若曝光和藏赞明显好于账号均值，第一段可加密到每周 3 篇教程
- 对比篇（第 6 期）的数据决定 Claude Code 段规模：若明显掉量，Claude Code 段缩减为 2-3 期，深度挪到公众号
