# 正文

前段时间有条技术新闻，大概率你刷到过又划走了：Coinbase 把 HTTP 协议里一个叫"402 Payment Required"的状态码用了起来，做成机器间支付协议 x402。

一个状态码而已，值得写篇文章吗？

我的判断是：这可能是"硅基经济"的出生证明之一。**AI 支付不是支付行业的一个新功能，而是一个新经济体开始自转的起点。**这篇文章讲清楚我为什么这么想。

[配图：一张对比图，左边1994年的电脑屏幕，右边一个AI agent的对话界面]

## 1994年，那张12.48美元的CD

1994年8月11日，一个美国人在网站 NetMarket 上买了一张 Sting 的专辑《Ten Summoner's Tales》，花了12.48美元。这笔交易用了加密技术保护信用卡信息，被公认为第一笔真正意义上的在线交易。

第二天《纽约时报》报道了这件事，标题平淡，公众反应也平淡。没有人宣布"电商时代来了"。

30年后，全球电商是十万亿美元级的经济体，它重写了零售、物流、广告、就业，顺手造出了亚马逊和阿里巴巴。

回头看，那张CD就是奇点。但在当天，它只是一条不重要的新闻。

> 所有奇点在发生的当天，看起来都像一条不重要的新闻。

我认为第一笔真正的机器自主支付——不是人点确认，而是 agent 自己判断、自己付钱——就处在同样的位置上。甚至它可能已经发生了，只是没人给它立碑。

## 一个睡了三十年的状态码，醒了

HTTP 协议在上世纪九十年代设计时，预留了 402 状态码，注释只有一句：为未来的数字支付保留。

它睡了三十年。因为人类的支付不需要它——我们有收银台、有跳转页面、有短信验证码。

2025年，它被密集唤醒。不是一家公司的动作，而是一整排：

- Coinbase 推出 x402，让机器可以在一次 HTTP 请求里完成"被要价、付款、拿到服务"；
- Google 发布 AP2（Agent Payments Protocol），拉了60多家机构，Mastercard、PayPal 都在名单里；
- Visa 和万事达各自发布了 AI 代理支付方案；
- OpenAI 和 Stripe 把下单能力直接塞进了 ChatGPT；
- 国内，支付宝也已经向 AI Agent 开放了支付接口。

**卡组织、云厂商、模型公司、支付巨头在同一年涌向同一个方向——这不是跟风，是卡位。**他们抢的不是一个功能的市场份额，是一个新经济体的地基。

> 协议层的战争，从来都发生在大众视野之外。

[配图：2025年各巨头AI支付布局时间线]

## 机器经济不是人类经济的加速版，是另一个物种

有人会说：机器付钱，不就是把付款按钮自动化了吗？

不是。先看一个具体画面。

你让一个 agent 帮你盯行业动态。半夜两点，它发现一份冷门报告，向数据商付了 0.3 美元，买下其中三页；凌晨四点，它调用一次翻译模型，花了 0.001 美元；早上七点，摘要准时出现在你手机上。一晚上十几笔交易，总共不到一美元，全程没吵醒你。

这个画面里，藏着三件人类经济做不到的事。

**几毛钱的生意，信用卡时代根本做不了**——手续费比交易额还高，商家等于倒贴。所以过去的互联网只能靠广告和包月来变现小额价值。而机器支付天然长在稳定币和链上结算上（稳定币，可以理解成锚定美元的数字现金，机器世界里流通的"钞票"），一笔 0.001 美元的交易也成立。按一次调用付费、按一条数据付费、按一秒算力付费，全都可行。

**不睡觉是第二件。**人类交易员有下班时间、有周末，agent 7×24 在决策和交易，全年无休。

**第三件是速度。**人类经济的心跳按天和月算——工资按月发，账期按季度结；机器经济的心跳按毫秒算。货币流通速度会是另一个量级，而货币流通速度，几乎定义了一个经济体的活力。

这三件事加起来意味着什么？此前所有"不值得做的生意"会同时复活。一条冷门数据、一个小模型的一次推理、一段闲置带宽，过去没法单独收费的东西，都会变成商品。

> 当交易成本趋近于零，长尾上沉睡的价值会被一次性点亮。

## 人退后一步，站到了更关键的位置

那人去哪了？

从"执行交易的人"，退到"设定预算和意图的人"。就像老板不亲自去报销每一张发票，只决定额度和规则：你给 agent 一个月100美元的预算，它自己决定买哪些数据、调用哪些服务。

这个位置的后退，会带来一串全新的问题：给 agent 多大的额度算合理？它花错了钱谁负责？怎么审计一个每秒做几十笔交易的"员工"？

**这些问题现在还没有答案，而没有答案的地方，就是未来十年新职业、新公司和新法律生长的地方。**审计 agent 消费的工具、给机器做信用评级的机构、处理机器交易纠纷的规则——今天听起来像科幻，1994年"网店客服""电商运营"听起来也像科幻。

[配图：示意图——人设定预算与意图，agent在下层高频交易]

## 为什么它现在如此不起眼

因为绝大多数 agent，今天还在刷人类的信用卡、登录人类的账号，像个拿着家长手机付款的小孩。

这恰恰是1993年的样子——当时也有电话拨号的网络购物实验，笨拙、小众、不值一提。基础设施差最后一块，整个大厦就显得像个玩具。

而现在，三块基础设施刚好凑齐了：模型有了自主决策的能力，支付有了机器原生的协议（x402、AP2），结算有了规模化的稳定币。

**奇点从来不在它发生的那天被承认，只在回头看的时候被追认。**

我不知道第一笔载入史册的机器支付会发生在哪条链、哪个协议上，也不知道这个"硅基经济"要几年才长到肉眼可见。但1994年到亚马逊上市，只用了三年。
