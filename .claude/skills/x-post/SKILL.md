# X 推文生成（中文）

将一个想法或选题转化为 X 平台的中文内容。X 是三平台里唯一承接全部三个板块的：**AI 使用分享 + 生活穿插 + 交易哲学（X 独占区）**——交易内容只哲学不行情（见 CLAUDE.md 通用红线）。X 中文圈的优质内容特征是**信息密度高、观点锋利、不绕弯**。

## 输入

一个想法描述，或 `ideas/` 下的选题文件路径。如果 `ideas/` 里有对应选题文件，先读它，以其中的核心观点和素材要点为准。

## 形态判断

先判断用单条还是 thread：
- **单条**：一个观点一句洞察就能说完的，宁短勿长，单条传播力更强。
- **Thread**：有多层论据或步骤的选题，5-10 条，第一条必须独立成立（钩子 + 承诺后文价值），最后一条收拢观点并引导转发/关注。

## 平台规则

- **长度**：X 对中文按 2 字符计数，每条上限 280 字符 ≈ **140 汉字**。写完自查每条字数，超限就拆分或删。
- **首条钩子**：反常识结论、具体数字、或尖锐提问开头。不用"今天聊聊……"这种慢热开场。
- **Thread 格式**：每条可用 `1/`、`2/` 编号；一条只说一个点；条与条之间有推进感。
- **语气**：直接、克制、有立场。不用感叹号堆情绪，用事实制造情绪。
- **标签**：最多 1-2 个（如 #AI #web3），或不用——X 上标签堆砌显得业余。
- **互动设计**：结尾条留一个可辩论的问题或立场，引发引用转发。

## 排版规范

X 是纯文本，排版只有一个工具：**换行**。

- **条内换行**：每条推文内部用 1-3 次换行切分语义块——钩子句独立一行，结论独立一行。整条挤成一坨的推文没人读。
- **空行**：条内可用空行（连按两次换行）制造停顿，一条最多 1 处空行；注意换行符也计入 280 字符。
- **并列点**：条内列点用换行 + "·" 或 "—" 前缀，不用 markdown 的 `-`（不渲染）。
- **数字与符号**：数据用阿拉伯数字（"3 年翻了 10 倍"比"三年翻了十倍"扫读更快）；中英文之间留一个空格。
- **编号**：thread 用 `1/ 2/ 3/`（含首条），读者刷到中间任一条都知道有上下文。
- **首条**：不放链接（外链会被限流），不放图也成立；引流内容放在末条。

## 配图（可选，定稿后）

**前置条件：仅在用户定稿后考虑。**X 不强制配图——每条 thread 默认 0-2 张，由内容决定，纯观点型 thread 裸发更有可信度气质；是否配图也纳入结构反模板轮换（上篇带图，这篇可以纯文字）。

- **比例**：16:9（1800×1013），直接复用 `wx-article/templates/` 的模板体系（金句卡/时间线等），X 的最佳展示比例正好与公众号插图一致。
- **优先级**：信息增量大的图优先（时间线、数据对比）＞首条钩子卡＞装饰性配图（不要）。
- **复用**：若同选题的公众号已生成同内容图片，直接引用 `wx/<主题文件夹>/` 下的文件，不重复渲染；X 专属的图渲染到 `x/<主题文件夹>/`。
- **标注**：在 thread.md 文末加"# 配图"一节，写明"第 N 条 → 文件路径"，未标注的条目即裸发。

## 去AI化（强制）

严格遵守项目 CLAUDE.md 的"叙事与受众规范"和"去AI化写作规范"（含"破除统计特征"）。X 观点可以锋利，但表达要通俗：术语带人话翻译，首条尽量用故事或场景开钩（而非纯判断句）。X 上 AI 腔一眼假，thread 尤其要防"节拍器感"：
- 各条句式不要雷同——禁止每条都走"观点句 → 解释 → 金句收尾"同一模板；
- 金句配额按 CLAUDE.md"破除统计特征"执行（thread 按条数计），其余条平收（以事实、细节或半截问题结束都行）；
- 各条长度别均匀，允许一条很短（一两行）、一条偏长；
- 至少一条带个人经历或具体场景。

初稿完成后按两份规范自查一遍再交付。

**结构反模板**：动笔前翻看 `x/` 下最近 2-3 篇 thread.md，形态（单条/thread）、首条开钩方式、条数、结尾动作与上一篇错开（轮换菜单见 CLAUDE.md"结构反模板"）。不要每次都是"8 条 thread + 结尾提问"。

## 红线

- **交付前必须按 `content-review` skill 的 X 一节做合规扫描**（重点防限流：首条无外链、标签 ≤2、不重发相同文本）。
- 金融话题不喊单、不做收益承诺，可加 NFA（not financial advice）语境。
- 不蹭无关热点标签。

## 输出

写入 `x/<YYYY-MM-DD-主题slug>/thread.md`，结构：

```markdown
# 形态
单条 / Thread（N 条）

# 内容
（单条直接给；thread 按条列出，每条后标注字符数）

# 备选首条
（另给 1 个不同角度的首条钩子，供 A/B 选择）
```

如果该主题文件夹已存在，直接更新其中的 thread.md。
