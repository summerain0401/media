# 平台合规审稿

对小红书、公众号、X 的文字稿做发布前合规扫描。背景教训：2026-07-13 小红书首篇因含 web3 标签、稳定币、Coinbase 等内容被判"仅自己可见"（静默限流，平台不通知），一篇稿子废掉整个冷启动。**审核不过，内容写得再好都是零。**

## 执行时机（两次，都是强制）

1. **初稿完成后、汇报给用户前**：全量扫描。审出问题直接改稿，改动在汇报中逐条列出（原句 → 改后句 → 原因）。
2. **用户定稿后、出图前**：快速复扫。修稿循环可能引入新的敏感表述，出图前最后把一遍关。

## 扫描范围

不只是正文。**标题候选、话题标签、封面文案、摘要、配图文案**全部在内——上次事故的触发点之一就是 #web3 这个标签本身。

## 判定分级

- ✅ **通过**：直接交付。
- ⚠️ **需修改**：列出每一处（原句 → 改写 → 原因），改完再交付。
- ⛔ **高风险**：选题与该平台红线正面冲突、降敏后内容失去意义的，建议该平台跳过或换角度重写，交用户决定。

## 小红书（三平台里最严，宁枉勿纵）

1. **加密货币/web3 一律禁，科普语境也不行**（实测被限流）：比特币、以太坊、稳定币、代币、币圈、链上、web3、区块链、Coinbase、币安、交易所、空投、挖矿、NFT、DeFi。选题绕不开时：小红书版做降敏改写（只讲 AI/技术/商业侧，把"币"的部分整体抹掉），或判 ⛔ 建议跳过。
2. **金融投资**：不荐股不喊单；不出现具体收益数字承诺；禁"上车""财富机会""看懂的人和没看懂的人命运不同"式暗示；"副业月入 X 万"式表述禁。
3. **广告法绝对化用语**：最、第一、顶级、国家级、绝无仅有、100%。
4. **站外导流**：微信、VX、公众号、加我、私聊、评论区扣 1、二维码、任何外链。
5. **营销号特征**：通篇课程感/成交感话术（"今天教大家""看到最后有福利"）会触发营销判定，新号尤其敏感。
6. **常规敏感**：医疗功效断言、政策监管的猜测性解读、灰色收入话题。

## 公众号

1. **加密货币可科普，禁诱导交易**：提及币种/协议/交易所只做事实陈述，不出现"值得买入""机会窗口""建议配置"式表述；涉及必附风险提示。
2. **金融资质红线**：不荐股、不预测具体标的涨跌、不做收益承诺。
3. **诱导分享**：禁"转发到朋友圈领取""不转不是"式利益诱导（正常引导关注/星标可以）。
4. **标题**：不用"震惊""删前速看""国家终于出手"式标题党，微信对标题夸张有专项处罚。
5. **时政**：只引用官方公开信息，不做阴谋论式解读。

## X

审核最宽松，重点防限流而非违规：

1. **Spam 特征**：首条不带外链；标签 ≤2；不同日重发相同文本。
2. **加密内容**：合法可发，但会招 scam bot 评论刷楼，发后留意评论区，别与之互动。
3. **金融**：不喊单，可加 NFA 语境（沿用 x-post 红线）。

## 三平台通用（CLAUDE.md 红线）

- 收益承诺 = 0，金融内容附风险提示。
- 数据和引用注明来源，来源存疑的数字删掉或改为约数并说明。

## 输出格式

汇报时每平台一行判定，需修改的附改动清单：

```
【平台审稿】
小红书：⚠️ 3 处已改（详见下）
公众号：✅ 通过
X：✅ 通过（提醒：涉加密话题，注意评论区 bot）
```

## 维护

平台红线是活的：每次实际发布遇到限流/违规通知，把新学到的红线写进本文件对应平台一节，注明日期和触发案例。
